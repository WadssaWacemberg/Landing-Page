Uma aplicação web completa para publicar e gerenciar conteúdo com autenticação e operações CRUD.

Categoria

Full Stack Engineering

Meu papel

Interface, API, autenticação e integração com banco em nuvem.

Stack

React · Node.js · JWT · REST

01 / Problema

Construir um fluxo confiável de identidade e conteúdo.

O sistema precisava proteger ações de escrita e manter a experiência de criação, leitura, atualização e remoção simples.

02 / Decisões

A autenticação JWT delimita operações protegidas; a separação entre interface e API mantém regras e apresentação independentes.
