FreshFood.

Aplicação ponta a ponta com autenticação, API documentada, persistência em nuvem e ambiente conteinerizado.

Categoria

Full Stack Engineering

Meu papel

Desenvolvimento da interface, API, autenticação, banco e deploy.

Stack

React · Node.js · JWT · PostgreSQL · Docker · Aiven

01 / Problema

Conectar experiência, regras e dados em uma aplicação coerente.

O projeto exigiu alinhar fluxos da interface, contratos da API, autenticação e persistência sem perder clareza operacional.

02 / Como projetei

A solução separa responsabilidades entre cliente, API REST e banco gerenciado. JWT protege os fluxos autenticados e Swagger torna os contratos verificáveis.
