Princípios de Engenharia

A tecnologia deve reduzir a complexidade.

As pessoas vêm antes do software.

Acessibilidade é engenharia.

A infraestrutura ensina humildade.

Os dados possuem uma história antes que a Inteligência Artificial a descubra.

Compreender usuários é engenharia.

O software deve conseguir se explicar.

A Inteligência Artificial deve ampliar as capacidades das pessoas.

Engenharia é empatia aplicada de forma sistemática.

A tecnologia só é inteligente quando não deixa ninguém para trás.
